# AeroBMSCE Website Redesign

A redesigned frontend for the AeroBMSCE recruitment task.
This project focuses on improving the visual appearance,
navigation, and user experience of the website.

## 1. Noticeable Flaws in the Original Website

The original website had scope for improvement in its visual
consistency, layout, and overall presentation. The content
and images could be presented in a more structured manner
to make the website easier to explore.

The visual design also needed a stronger aerospace identity
to reflect the team's work in aviation, drones, and aerospace
technology.

## 2. Design Approach and UI/UX Decisions

I chose a modern, space-inspired visual theme using midnight
blue backgrounds, contrasting text, and gold accents to create
an aerospace-focused identity.

The main design decisions included:

- Improving the visual hierarchy of headings and content.
- Using a consistent colour palette across the pages.
- Organising content into clear sections for easier browsing.
- Improving navigation between the Home, Journey, and Partners
  pages.
- Using relevant images and visual elements to strengthen the
  aerospace theme.
- Maintaining a responsive layout for different screen sizes.

The goal was to create a cleaner, more engaging website while
keeping the content easy to understand and navigate.

## 3. Challenges Faced and Solutions

One challenge was maintaining visual consistency across
multiple HTML pages while updating the overall design.

I addressed this by using a shared CSS stylesheet and applying
consistent colours, spacing, typography, and layout rules.

Another challenge was ensuring that the website and its assets
worked correctly after deployment using GitHub Pages. I
checked the deployed website and verified that it loaded
without visible glitches.
